# The Mosaic Story

Written by Ileana Pirozzi, illustrated by Nancy Tran. A scroll story: one painted landscape stays pinned while the text scrolls and the view moves to each part of the picture.

Plain static site, no build step. `index.html` is self-contained; the fluoroscopy frame is in `img/`.

Also published at https://nancytuongtran.com/mosaic-story
